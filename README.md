# Thamsanqa Hadebe - Developer Portfolio

![Portfolio Screenshot](./screenshot.png) <!-- Add actual screenshot later -->

A modern, animated portfolio website showcasing my skills, certifications, and projects as a self-taught developer. Built with Supabase-inspired UI animations and a sleek dark theme.

## ✨ Features

- **Supabase-Inspired Animations**:
  - Smooth fade-in transitions
  - Interactive hover effects
  - Shimmer loading animations
  - Scroll-triggered animations

- **Modern Design**:
  - Dark theme with vibrant accents
  - Responsive layout for all devices
  - Clean typography with Inter font
  - Card-based UI components

- **Content Sections**:
  - Hero section with call-to-action
  - About me with skills matrix
  - Certifications showcase
  - Projects gallery
  - Contact form

## 🛠 Technologies Used

- **Frontend**:
  - HTML5, CSS3, JavaScript
  - CSS Animations and Transitions
  - Responsive Design (Flexbox, Grid)
  - Intersection Observer API

- **Design**:
  - Supabase UI inspiration
  - Custom color palette
  - Modern card components
  - Micro-interactions
